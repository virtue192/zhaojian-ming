# 照见 · 明朝抉择档案 0.3

[在线体验](https://virtue192.github.io/zhaojian-ming/) · [开源仓库](https://github.com/virtue192/zhaojian-ming)

十二个历史与生活关口，二十四位历史参照。包含八位女性、青年创作者、长期求知者、诗画与思想人物，以及公共行动和宫廷人物。匹配不根据玩家性别、年龄或职业筛选。

纸张质感、墨绿朱砂、原创 SVG 山川插画。基础玩法无须账号或 API Key。支持人物搜索、主题浏览、取舍解释、改一关预览、文本档案、PNG 与 SVG 分享卡片。

## 本地启动

需要 Node.js 22 或更新版本，无第三方运行依赖。

Windows 双击 `启动照见.cmd`，会启动本机服务并打开 http://127.0.0.1:4187 。同目录也可运行 `npm start`，按 Ctrl+C 停止前台服务。运行 `停止照见.ps1` 可停止一键启动器所创建的后台进程，脚本会先校验进程路径。

其他系统也可使用 `npm start`。若端口占用，设置 `PORT` 环境变量后运行；一键启动器固定使用 4187。

## GitHub Pages

`public/` 是完整的静态网站，所有资产与模块使用相对路径，可部署在 `/仓库名/` 子路径，无须构建。

将本项目目录内的源码上传为 GitHub 仓库内容。仓库 Settings → Pages → Source 选择 GitHub Actions。默认分支使用 `main`；若名称不同，修改 `.github/workflows/pages.yml`。工作流先运行语法检查和测试，再发布 `public/`。首次可从 Actions 手动触发。

也可把 `public/` 的内容作为静态发布目录。不要把 `.runtime/`、日志、真实 Key 或本地配置提交到仓库。Key 不属于仓库 Secrets，也不应注入静态网站构建。

本项目使用 GitHub Actions 将 `main` 分支的 `public/` 自动部署到 [GitHub Pages](https://virtue192.github.io/zhaojian-ming/)。部署先运行语法检查与测试，再发布网站；流程状态可在仓库 Actions 查看。

工作流参考：[GitHub Pages 自定义工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## BYOK 两种运行方式

右上角配置 Base URL、模型 ID、API Key。

| 方式 | 请求路径 | 适用情况 |
| --- | --- | --- |
| 浏览器直连 | 页面 → 用户指定的模型接口 | GitHub Pages 与其他静态托管；服务须允许 CORS |
| 本机代理 | 本地页面 → 本机 Node 服务 → 模型接口 | 下载运行，使用不接受浏览器跨域调用的服务 |

静态网站默认浏览器直连并禁用本机代理选项；本地根页面默认本机代理，也可切换直连。不会自动转发到未知代理。

采用 Chat Completions 文本协议。例如 `https://api.deepseek.com` 或 `https://example.com/v1`，程序补上 `/chat/completions`。完整接口地址也可使用。本机服务可填写 `http://127.0.0.1:11434/v1`，并提供服务接受的非空占位 Key。供应商专有 Messages/Responses 协议尚未适配。

预置 DeepSeek 是参数示例；模型名称可修改。真实服务商 Key 与从实际 Pages 域名出发的跨域请求尚未实测，不能承诺所有兼容协议的服务都能在浏览器使用。[CORS 说明](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS)、[DeepSeek 接口协议](https://api-docs.deepseek.com/api/create-chat-completion/)。

- Key 仅留在页面内存中，刷新清除；关闭设置会清空输入框，断开连接会清除内存 Key。
- 本地存储只保存非密钥配置；当前回答保存在 sessionStorage。
- 测试连接会发一次简短请求，生成解读会发送十二次选择与提供的历史记录，费用由模型服务商收取。
- 所有模型输出经过结构校验，并作为纯文本呈现；模型不能修改本地匹配。
- 失败、取消与重试保留基础档案；已有 AI 解读重新生成失败时亦会保留。
- 本机服务仅监听 127.0.0.1，不跟随模型接口重定向，超时为 60 秒，拒绝跨域网页使用本机代理。

## 内容和匹配

旧版六关保留，新增本草重编、远行与牵挂、天工入书、画笔与生计、让声音留下、情与规矩。历史背景、虚构玩家角色和选项分别存放，每题附来源。

每个人物的 `pattern` 是作者根据历史主题归纳的游戏取舍画像，不是人物对未参与事件的真实回答。匹配逐题比较该画像与玩家选择：三个相关关口权重为 2，其他关口为 0.8，完全相同的游戏选项距离为 0，否则结合选项的八项编码计算距离。加权平均距离较小者成为参照，前两位距离差小于 0.03 时提示接近。

八项编码用于解释担当、审慎、原则、变通、求实、协作、自主与表达。编码、画像、权重与阈值均为娱乐性设计，未经心理测量验证；不提供能力判断、人格诊断或命运预测。

人物卡注明史料观察阶段。叶小鸾等青年人物的记录范围较窄；商人、工匠、普通劳动者和儿童记录仍需扩充。

## 存档与版本

应用版本 `0.2.0`，题库 `ming-2`，评分 `event-pattern-1`。新回答使用稳定事件与选项 ID。旧版六关数字回答显式迁移，保留前六关后继续新增关口。题库或评分版本不一致时，拒绝按新规则悄悄解释旧存档。报告包含版本，改题或改规则需更新对应版本。

“改一关试试”先用临时副本计算，原档案不变；选择“采用这一步”才保存新回答，并清除旧 AI 解读。

## 源码结构

- `public/events.js`：12 关背景、选项、稳定 ID、来源与游戏编码。
- `public/people.js`：24 人物实际记录、观察阶段、来源与作者画像。
- `public/quotes.js`：24 条题句、作者、文献类型、来源与解说。
- `public/pointer.js` / `atmosphere.css`：原创光标、点击与聚光。
- `public/typography.css` / `fonts/`：本地字体与独立许可。
- `public/share-card.js`：字体内嵌 SVG 与 PNG 导出。
- `public/engine.js`：逐关匹配、解释、存档迁移与报告。
- `public/byok.js`：浏览器和本机服务共享的模型协议与校验。
- `public/app.js`：答题、浏览、取舍预览、设置与下载。
- `server.mjs`：可选的无依赖本机服务。
- `.github/workflows/pages.yml`：静态 Pages 发布流程。
